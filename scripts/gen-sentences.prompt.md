# 문장 생성 지침 (gen-sentences.prompt.md) v1

레벨별 읽기 연습 문장을 만든다. 앱은 문장을 보여 주고 **한글 발음만** 채점한다(뜻 입력 없음).
결과 화면에서 번역·문장 속 단어·듣기(기기 일본어 음성)를 보여 준다.

## 항목 형식 (`data/sentences/<level>.json`)

```json
{ "ja": "私は学生です。", "kana": "わたしは がくせいです。", "ko": "저는 학생입니다.", "words": ["私", "学生"] }
```

- `ja`: 한자 보기에서 보이는 문장. 그 레벨에서 흔히 한자로 쓰는 말만 한자로 쓴다. 숫자는 한자(三時)로 쓴다 — 아라비아 숫자 금지.
- `kana`: 가나 보기에서 보이는 문장이자 채점 기준. **어절(문절)마다 공백 하나**로 띄운다(교과서식 わたしは がくせいです。).
  조사는 앞 말에 붙인다. 외래어는 가타카나 그대로. 문장부호는 。、？ 만 쓴다.
- `pron`(선택): 자동 규칙이 틀릴 때만 쓴다. `kana`와 같은 문자열에서 실제 발음만 바꾼 것.
  자동 규칙 — を는 항상 お, 어절 끝의 は는 わ, 어절 끝의 へ는 え(はなは → はなわ, がっこうへ → がっこうえ).
- `ko`: 자연스러운 한국어 번역 하나(채점에 안 쓰고 보여 주기만 한다).
- `words`: 문장에 나온 **내용어의 사전형 표제어**(그 레벨 단어 데이터의 word). 활용형이 아니라 사전형(行きます → 行く).
  조사·조동사·です/ます는 넣지 않는다. 같은 표기 단어가 둘이면 `"word:reading"`으로 쓴다.

## 내용

- 그 레벨 어휘·문법만 쓴다(N5: です/ます, ました/ません, て形·てください·ています, たい, ましょう, でしょう, ～から·ので, 형용사 활용, あります/います, 기본 조사).
- 한 문장 3~6어절. 일상에서 실제로 쓸 말. 같은 문형만 반복하지 않는다.
- 사람 이름·지명 등 고유명사는 쓰지 않는다(그 레벨 단어로 대신한다).
- 읽기가 둘 이상인 한자 표기(家 いえ/うち, 方 ほう/かた)는 문맥상 자연스러운 읽기를 `kana`에 쓴다.
